Dainric

通用加载动画

四种形态 · 纯 CSS 驱动 · 无依赖 · 支持深浅色与自动降级

接入方式

// 1) 全屏遮罩（默认）
Loader.init({ brand:'Dainric', variant:'ios', size:48, theme:'dark' });
Loader.hide();

// 2) 内联到任意容器
Loader.mount(document.querySelector('.card'), {
  variant:'flow', size:56, label:'正在同步'
});

// 3) 确定性进度
const p = Loader.mount(el, { variant:'progress', size:88 });
p.set(0.42);            // 平滑过渡，无需自己做缓动
p.done();

// 4) 旧版 API 完全兼容
Loader.init({ dots:7, duration:2400, onDone:fn });
