Dainric 打包器 v4.1.1  使用说明
作者：Dainric
================================================================

一、这是什么
----------------------------------------------------------------
把 Python 脚本打包成单个 EXE 的 Windows 桌面程序。
不需要联网，不需要装 Python —— 需要的运行时已经随程序一起安装好了。

产物是真正的独立 EXE：拷到任何一台 Windows 机器上双击即可运行，
目标机无需安装 Python、无需安装 .NET。


二、快速开始
----------------------------------------------------------------
1. 打开「单文件打包」页
2. 把要打包的 .py 拖进窗口（或点「选择脚本」/按 Ctrl+O）
3. 程序会自动识别脚本的版本号、GUI/命令行特征（见第六节）
4. 需要的话改一下产物名称、图标、版本信息；要带数据文件就展开「高级参数」
5. 按右下角「开始打包」（或按 F5）
6. 打包完成后，结果卡会显示产物大小、SHA256，并可一键打开/运行产物
7. 也可以直接在资源管理器里右键一个 .py →「用 Dainric 打包」

第一次打包会慢一些（要建立分析缓存），之后会明显变快。


三、四个页面
----------------------------------------------------------------
单文件打包
    主界面。选脚本、起名、设图标、设版本、选窗口模式。
    勾「打包后自检产物」会在结束后自动启动一次产物，
    确认「能打包」的同时也确认「真能跑起来」。
    「试运行脚本」可以先用打包引擎的 Python 跑一遍脚本。

依赖 / 历史
    依赖分析：扫脚本的 import，确认目标运行时里真的装了这些模块。
    缺依赖会在打包前就拦下，不会等到产物启动才报错。
    打包历史：每次打包的时间、脚本、产物、大小、耗时、成功/失败，
    关闭程序后也会保留（存在 %LOCALAPPDATA%\Dainric\history.json）。
    双击记录打开产物位置；右键可以重新载入脚本、复制诊断信息、删除记录。

运行时
    查看 Python 运行时状态（版本、位置、PyInstaller 版本、来源）。
    可以指定运行时的位置，程序会记住。
    装完即用，一般不需要动这一页。

批量打包
    一次拖入多个脚本，排队逐个打包。
    每个脚本各自独立，一个失败不影响后面的。
    每项会显示状态、耗时、产物大小；跑完可以「只重跑失败项」，
    也可以「导出结果」为 CSV 表格。


四、日志面板
----------------------------------------------------------------
右侧「输出日志」是排障的主要入口：
- 搜索框：按关键字过滤日志；「只看异常」只看警告和错误
- 「自动滚动」：新日志出现时自动滚到底部
- 「放大」：日志面板铺满整行（Esc 还原）
- 「导出」：把当前日志另存为 .log 文件
- 每次打包结束，完整日志会自动保存到
  %LOCALAPPDATA%\Dainric\logs\ 下，反馈问题时可以直接发送

鼠标左键拖动日志面板左侧的分隔条，可以调整日志宽度。


五、高级参数与数据文件（v3.3.0 新增）
----------------------------------------------------------------
「高级参数（可选）」卡默认留空即可，只有自动修复仍失败时才需要动它：

- hidden-import：手动补充 PyInstaller 静态分析找不到的模块，
  多个用逗号或空格分隔。打包失败诊断里提到「在高级参数里填 hidden-import」
  就是填在这里。
- 排除模块：用 --exclude-module 排除不需要打进包的大库（减小产物）。
- 额外参数：原样传给 PyInstaller，例如 --collect-all 某库。
- 附加数据文件：脚本要读的 json/csv/图片/模板等，点「添加文件」或
  「添加目录」后会自动加进产物；运行时文件位于 sys._MEIPASS 下。
  点「用法代码」会复制一段 resource_path() 函数，用它可以找到这些文件：
      open(resource_path("data.json"), encoding="utf-8")

这些设置会记住，下次打开程序还在（批量打包也会带上）。


六、脚本识别与试运行（v3.3.0 新增）
----------------------------------------------------------------
选择脚本后，脚本卡下方会显示自动识别结果：
- 脚本里有 __version__ = "1.4.2" 会自动填到「输出 → 版本」
- import 了 tkinter / PyQt / PySide / wx / pygame 等 → 提示建议无控制台
- 用了 input() / argparse → 提示建议控制台
- 用了 multiprocessing → 提示产物需要 freeze_support
- 出现 __file__ / open(...) → 提示可能读取外部文件（去第五节省事）

「试运行脚本」会用当前打包引擎的 Python 启动一次脚本，
弹出控制台窗口显示运行结果，适合打包前先确认脚本本身没问题。
注意：需要命令行参数的脚本，试运行可能提示用法错误，这是正常的。


七、打包结果卡片（v3.3.0 新增）
----------------------------------------------------------------
单文件打包完成后，右侧状态卡会出现「打包成功」结果卡：
- 产物大小、耗时、完整路径
- SHA256 校验值（长按可选中复制）
- 按钮：打开位置 / 运行产物 / 复制路径

打包失败时结果卡会显示失败原因；如果诊断出了具体问题，
会出现「复制诊断」按钮，一键复制后可以直接发给别人排查。


八、快捷键
----------------------------------------------------------------
Ctrl+O          选择脚本
F5 / Ctrl+Enter 开始打包（批量页则是开始批量）
Esc             停止当前打包 / 还原放大的日志面板
Ctrl+L          清空日志
Ctrl+Shift+C    复制全部日志


九、会自动处理的问题
----------------------------------------------------------------
打包失败时程序会读 PyInstaller 的报错，给出中文诊断和处理建议，
而不是只丢一句「失败」。

如果诊断结论是「缺少某个模块」，程序会自动把它加进 hidden-import
并重试，最多三次，成功后会告诉你第几次修好的。

如果打包本身成功、但产物一启动就崩（最常见的原因是模块是被动态导入的，
PyInstaller 静态分析发现不了），自检会抓住它，同样是自动补 hidden-import
再重试。


十、关于与版本
----------------------------------------------------------------
点右上角「关于」可以查看版本、构建时间、安装位置，
并可打开安装目录、日志目录、使用说明，或一键复制诊断信息。

版本号唯一来源是程序自带的版本信息；标题栏、启动日志、「关于」页
显示的是同一个版本。


十一、出问题时
----------------------------------------------------------------
产物启动即崩、又看不到报错：
    把窗口模式改成「控制台」重新打包，再运行一次产物，
    报错信息会直接显示在黑窗口里。

提示找不到运行时：
    打开「运行时」页确认状态。3.12 和 3.14 都已随程序安装。
    如果位置被挪动过，在那一页手动指定一次即可，程序会记住。

杀毒软件误报：
    单文件 EXE 是自解压结构，容易被启发式误判。
    加白名单即可，或在打包时改用「目录」形态（不是单文件）。


十二、运行环境
----------------------------------------------------------------
Windows 10 / 11 64 位
程序本体自包含 .NET 运行时，无需另行安装

内置运行时：
    Python 3.12（默认，兼容性最好）
    Python 3.14（较新语法特性）


十三、安装位置与数据目录
----------------------------------------------------------------
程序：  %LOCALAPPDATA%\Programs\Dainric
运行时：%LOCALAPPDATA%\Dainric\runtime-py312
        %LOCALAPPDATA%\Dainric\runtime-py314
配置：  %LOCALAPPDATA%\Dainric\config.json
界面状态：%LOCALAPPDATA%\Dainric\ui.json
历史：  %LOCALAPPDATA%\Dainric\history.json
日志：  %LOCALAPPDATA%\Dainric\logs\

卸载时以上内容会一并清除，不留残留。


十四、命令行模式（v4.0.0）
----------------------------------------------------------------
给自动化 / CI 用：不打开界面，直接打包并返回退出码。

用法:
    Dainric打包器.exe --build app.py [选项]

常用选项:
    --out <目录>            输出目录（默认 桌面\Dainric产物）
    --name <名称>           产物名（默认脚本名）
    --onefile / --onedir    单文件 / 目录形态
    --console / --noconsole 窗口模式
    --icon <app.ico>        产物图标
    --app-version <x.y.z>   写入产物版本资源
    --hidden-import <m>     手动 hidden-import（可重复）
    --exclude-module <m>    排除模块（可重复）
    --add-data <源;目标>    附加数据（可重复）
    --extra <参数>          追加 PyInstaller 参数（可重复）
    --no-selftest           跳过产物自检
    --json                  输出 JSON 结果（供脚本解析）
    --sign-pfx / --sign-password / --timestamp-url
                            打包成功后签名（见第十五节）

退出码: 0 成功 / 1 失败 / 2 参数错误。
完整帮助: Dainric打包器.exe --help

示例:
    Dainric打包器.exe --build app.py --out dist --onedir --json
    Dainric打包器.exe --build app.py --app-version 1.2.3 --sign-pfx cert.pfx


十五、代码签名（v4.0.0）
----------------------------------------------------------------
单文件 EXE 容易被杀软启发式误报，给产物加数字签名可以显著缓解。

UI：展开「高级参数（可选）」最下方的「代码签名（可选）」，
选择 .pfx 证书、填密码（可选填时间戳 URL），打包成功后会自动签名。
CLI：--sign-pfx <证书> --sign-password <密码> [--timestamp-url <URL>]

说明:
- 使用 Windows 自带的 Authenticode（Set-AuthenticodeSignature），
  不需要安装 Windows SDK / signtool。
- 自签名证书签出来的状态是 UnknownError（因为根证书不被信任），
  但签名本身已经写进产物的 PE 头；正式发布建议买代码签名证书。
- 密码只保存在内存里，不写入配置文件。


十六、单实例与右键菜单（v4.0.0）
----------------------------------------------------------------
- 程序是单实例：已经开着时再双击，不会开第二个窗口，
  而是把新打开的 .py 交给已运行窗口并激活它。
- 安装包会注册右键菜单「用 Dainric 打包」（.py / .pyw），
  按当前用户注册，不需要管理员权限；
  卸载时会自动清理。
- 也可以把 .py 拖到程序图标上启动。


十七、检查更新（v4.1.0）
----------------------------------------------------------------
- 右上角「关于」→「检查更新」可以手动检查新版本。
- 默认启动时静默检查，每天最多一次；「关于」页可以关闭该开关。
- 检查地址是 GitHub Pages 上的静态清单，不需要自建服务器：
      https://dainric.github.io/DainricPacker/update/latest.json
- 发现新版本后会显示更新说明，并可以打开安装包下载页。
- 检查失败不会弹错误，不影响正常打包；离线环境可以放心使用。
- 更新清单里同时提供安装包和绿色版的 SHA256，下载后可自行校验。


十八、一键卸载（v4.1.1）
----------------------------------------------------------------
- 右上角「关于」→ 左下角「卸载」可以一键卸载。
- 安装版会调用安装目录里的 unins000.exe，
  先退出程序，再清理程序、内置运行时、配置、历史、日志。
- 不会删除你自己打包出来的产物。
- 绿色版没有卸载程序，直接删除程序文件夹即可；
  数据目录在 %LOCALAPPDATA%\Dainric，可手动删除。
- 卸载后如果提示文件被占用，重启电脑再删一次即可。
